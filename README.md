# Music Interface — HTML / CSS Coursework

A static music-interface layout exploring navigation, sidebars, cards and media
controls. The repository contains a browser UI prototype, not an authenticated
music service or working streaming backend.

[Engineering portfolio](https://github.com/miguelcastu/miguelcastu) · [Project directory](https://github.com/miguelcastu/miguelcastu/blob/main/PROJECTS.md)

## Explore

Open [index.html](index.html) in a browser. Styles are in [index.css](index.css);
the local image files supply the exercise's visual assets. No dependency install
or build is required.

The original interface labels are Spanish. Placeholder navigation and the
referenced sample audio are incomplete. Responsive behavior and accessibility
have not been comprehensively tested. Images retain their original provenance;
no new license is asserted for third-party assets.
